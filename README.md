# 🔴 Don't Press The Button

A useless, fun and surprisingly addictive web toy.

The goal is simple:

**Don't press the button.**

But you probably will. 😈

---

## 🎮 Features

- 🔴 Interactive button
- 🎯 Score system
- 🏆 High-score tracking
- 🏃 Button movement
- 😂 Random funny messages
- 💥 Particle animations
- 🌙 Dark/light mode
- ⚡ 15-click challenge
- 🥚 Hidden keyboard Easter egg
- 💾 Local storage
- 📱 Responsive design
- ✨ Smooth animations

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage API

No frameworks required.
